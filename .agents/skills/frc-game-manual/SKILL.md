# FRC Game Manual

Ground rule and legality answers in official season-specific sources.

## Source Discipline

- Treat rule text as binding; treat headings and blue boxes as summaries or guidance.
- Apply Team Updates and consult the official Q&A when relevant.
- Cite rule numbers, sections, tables, pages, or update numbers.
- Never carry rules, scoring values, or robot constraints across seasons.
- Verify live FIRST season materials before giving a current answer.

The bundled 2026 manual and combined Team Updates are snapshots retrieved May 21, 2026. They are useful for local search but are not guaranteed to be the latest revision.

## Routing

- Read `references/manual-conventions.md` for manual structure and penalty vocabulary.
- Read `references/2026-rebuilt.md` for orientation only, then verify exact wording in the official PDFs.
- Read `references/pdf-patterns.md` for extraction, table parsing, and rendering workflows.
- Read `references/source-links.md` for official URLs and snapshot provenance.
- Use a PDF rendering workflow whenever layout, diagrams, dimensions, or tables affect the answer.
