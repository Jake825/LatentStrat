# Season and Event Phases

Use this reference to classify the analysis phase before deciding feature eligibility.

## Season Phases

- Offseason: useful for scouting context, but not official current-season performance.
- Preseason: robot reveal, practice, Week 0 style data, and early scouting signals.
- Pre-event: official event is known, but matches have not been played.
- Between official events: prior official events are known; later events are not.
- Post-season: all official results are known and historical analysis is allowed.

## Event Phases

- Before schedule release: team list may exist, but match pairings are unknown.
- After schedule release: pairings and match order can be used if released before the prediction.
- During qualifications: only completed earlier matches are known for later qualification predictions.
- Between qualifications and alliance selection: qualification results and rankings are known; alliance selection may not be.
- After alliance selection and before playoffs: playoff alliances and bracket context may be known; playoff results are not.
- During playoffs: only completed playoff matches are known.
- After event: final results, rankings, awards, OPR, and event summaries are known.

## Dashboard Guidance

- Live dashboards should mark partial data clearly.
- Post-event dashboards may summarize final results but should not feed those summaries into earlier predictions.
- Season dashboards should distinguish official events, district championships, championship divisions, Einstein/finals, preseason, and offseason events.
