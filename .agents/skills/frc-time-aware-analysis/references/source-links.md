# Source Links

Use these sources when checking current official timing, event, and data semantics.

- FIRST Season Materials: https://www.firstinspires.org/resources/library/frc/season-materials
- FIRST District and Regional Events: https://www.firstinspires.org/resources/library/frc/district-regional-events
- FIRST Championship Eligibility: https://www.firstinspires.org/resources/library/frc/championship-eligibility
- TBA Events: https://www.thebluealliance.com/events
- TBA API docs: https://www.thebluealliance.com/apidocs
- Statbotics API docs: https://www.statbotics.io/api

## Guardrails

- Official FIRST materials determine when rules, Team Updates, and advancement policies apply.
- TBA and Statbotics are data sources; inspect returned fields and timestamps before assuming temporal meaning.
- If live data is being used during an event, preserve the retrieval time or match cutoff used to build the dataset.
