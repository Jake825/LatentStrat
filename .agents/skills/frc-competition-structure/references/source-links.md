# Source Links

Use these sources to verify live event and advancement semantics when implementation depends on current rules or source behavior.

- FIRST District and Regional Events: https://www.firstinspires.org/resources/library/frc/district-regional-events
- FIRST Championship Eligibility: https://www.firstinspires.org/resources/library/frc/championship-eligibility
- FIRST Season Materials: https://www.firstinspires.org/resources/library/frc/season-materials
- TBA Events: https://www.thebluealliance.com/events
- TBA API docs: https://www.thebluealliance.com/apidocs

## Guardrails

- FIRST season materials and Team Updates are authoritative for current-season advancement and tournament rules.
- TBA is the practical source for event metadata, match schedules, rankings, awards, district points, and keys.
- When FIRST rules and a derived data source appear to disagree, quote the official rule source and inspect the raw TBA payload before coding assumptions.
