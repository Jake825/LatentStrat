# LatentStrat V5.7 Sensor Fusion

V5.7 extends the V5.6.1 prior-initialized Set Transformer with public TBA
sensor-fusion targets. The match table remains the primary training spine, while
rankings, alliance selections, and playoff outcomes are optional sidecar labels.

## Match-Spine Targets

The 2026 score-breakdown mapper translates TBA's game-specific JSON into generic
model-facing columns:

- `atomic_*` count targets from the 2026 `hubScore` counts.
- `committed_*foul*` targets, with TBA's awarded foul points inverted.
- `bonus_*` binary threshold targets.
- `special_*` binary penalty targets.

If a score breakdown is missing, the official match row stays in the table and
the V5.7 targets are `NaN`. Training masks those entries so missing breakdowns
do not poison the homoscedastic loss balancer.

## Relational Sidecars

`build-features --sidecar-output-dir ...` can write:

- `rankings_YYYY.parquet` from TBA event rankings.
- `selections_YYYY.parquet` from TBA alliances plus rankings-derived
  `passed_over_team_key`.
- `playoffs_YYYY.parquet` from event playoff alliances and finish status.

Declines are intentionally excluded because TBA does not reliably populate them
in live event data.

## Model Additions

The model adds alliance heads for atomic counts, committed fouls, bonus logits,
and special logits. It also adds:

- `TeamValueHead` for qualification rank pair losses.
- `AllianceValueHead` for playoff alliance ordering losses.
- A task-name keyed homoscedastic balancer covering match tasks and optional
  sidecar tasks.

Binary heads return logits only. Training uses masked `BCEWithLogitsLoss`.

## Training

Match-only training remains the default:

```bash
latentstrat train-features data/features_2026.parquet
```

Sidecar training is optional:

```bash
latentstrat train-features data/features_2026.parquet \
  --rankings-sidecar data/v57_sidecars/rankings_2026.parquet \
  --selections-sidecar data/v57_sidecars/selections_2026.parquet \
  --playoffs-sidecar data/v57_sidecars/playoffs_2026.parquet
```

The match loader drives the epoch. Non-empty sidecar loaders are cycled, and
empty sidecars are skipped.
