# LatentStrat V6.1

V6.1 is a stabilization release. It keeps the tested supervised Set Transformer shape while
cleaning package boundaries, CLI naming, artifacts, and offline representation workflows.

## Supported Areas

```text
latentstrat.pretraining.prior
latentstrat.pretraining.match_breakdown
latentstrat.season
latentstrat.artifacts
```

Unfinished frozen award, ranking, pick, and venue-mode work lives under `latentstrat.experimental`.
Developer-only reports live under `latentstrat.dev`.

## Stable Model Contract

The season model still uses:

```text
z_team_event = Z_base[team] + Z_event[team, event]
```

Schema-`6` registered module names and state-dict keys remain compatible. The forward return value
is now structured as representations, keyed task predictions, and slot masks. Internal legacy
metadata keys remain readable for one release.

## Pretraining Workflows

The Day Zero prior distills narrative, normalized EPA trajectory, and cultural signals into team
base embeddings. The match-breakdown workflow trains season-specific encoder/decoder routes around
one shared 16D alliance-result bottleneck. The structured V2 match-breakdown objective is an
explicit ablation and does not replace the V1 inspection baseline.

Neither match-breakdown artifact is attached to season training yet.

## Artifacts

New writers emit `manifest.json` with the workflow, artifact version, UTC timestamp, Git SHA,
resolved configuration, source hashes, output hashes and sizes, and promotion status. Generated
files remain local and ignored.

## Compatibility Window

- Flat CLI aliases print V6.2 removal warnings.
- Historical schema-`6` checkpoint metadata remains readable.
- Historical match-breakdown artifact readers remain available.
- New code must not import `latentstrat.world_model`.
